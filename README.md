# Sales Data Analysis

## Project Overview

This project analyzes sales data using Excel and SQL to explore sales performance, product and customer performance, trends over time, and patterns within the dataset.

The goal was to analyze the data from different perspectives and turn the findings into clear, useful insights.

## Tools Used

- Excel
- SQL

## Analysis

The analysis focused on:

- Sales performance and trends
- Product performance
- Customer performance
- Changes in sales across different periods
- Product demand and quantity patterns
- Key insights from the dataset

## Excel Dashboard

An Excel dashboard was created to present the main findings from the analysis in a clear and accessible format.

![Sales Dashboard](sales_dashboard.png)

## SQL Analysis

SQL was used to explore the dataset further and answer specific business questions.

The SQL analysis examined areas such as sales performance, product and customer performance, trends over time, and product demand.

The SQL queries used for the analysis are included in this repository.

## Project Report

A detailed report accompanies the project and documents the analysis, SQL queries, findings, and key insights.
